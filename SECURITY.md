# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability, please report it responsibly to:

**Email:** bender@impactia.org

Do not open a public GitHub issue for security vulnerabilities. Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce (if applicable)
- Any proof-of-concept code or details
- Your name and contact information (optional, but appreciated)

We will acknowledge your report within 48 hours and work with you to understand and resolve the issue.

## Supported versions

Currently, only the `main` branch receives security updates. We recommend staying on the latest version.

## GDPR and privacy rights

This project honors data protection rights globally:

- **Privacy requests:** If you believe personal data is included in this index, you can request correction or removal
- **Contact:** bender@impactia.org
- **Rights:** We honor GDPR and similar privacy principles regardless of your location

Send privacy or data removal requests to the above email with:

- Your name and contact information
- A description of the concern
- Relevant URLs or details

We will respond within 30 days and take appropriate action.

## Security practices

- Dependencies are regularly reviewed and updated
- Code is tested before merge via CI
- The project follows the Apache-2.0 license and open-source practices
- This is a pre-release project; use with caution in production

Thank you for helping keep this project secure.
