Why

Web search was built for people. Agents need their own.

For decades web search has belonged to a handful of companies indexing hundreds of billions of pages. An open alternative at that scale was never realistic: the infrastructure cost is enormous, and the index would be far too large to share. So we asked what an agent actually needs.

Precision first

An agent answering a legal question has to read the exact statutory text before it answers. It needs the authoritative source itself, not a page about it.

Fresh, not months old

A model is trained on data that is months old by the time it ships. Search is how an agent sees what changed since.

Sovereign all the way down

Open-weight models make sovereign LLMs possible. An agent that still sends every query outside your perimeter is only half sovereign.

Yours to keep and to change

The code and the index are open. A foundation keeps the core index honest, and anyone can run it, fork it or add their own sources.

How it fits

Agents don't need the web the way people do.

Two differences let us redesign the index from scratch, for size and for sharing.

The model already carries a compressed web

So the index only has to fill in what the model lacks: the exact text, the current state, the authoritative URL.

A good entry point is enough

Agents don't need the perfect page in the top three results. Given a good entry point, they walk the site themselves and find the best page in seconds.

Sizes

Three sizes of common.

The same software runs every size. The index lives on NVMe; RAM buys speed, not feasibility. At the full size, private, sovereign web search becomes practical for a team, a company or a country.

Connect an agent

Add the hosted endpoint to your MCP client. The agent gets one tool, search, which returns the URL of the authoritative source with the minimum context needed to choose.

Your own deployment exposes the same endpoint on your own host.

Who's behind it

Two stewards, one commons.

Cytir is a collaboration between impactIA, a Geneva-based foundation, and Vector8, a European AI consultancy. Code and index ship under Apache-2.0.

impactIA governs the open-source community and the contents of the core index. The foundation is based in Geneva.

Vector8 contributes resources to the community and offers deployment and customisation services for enterprises. Offices in Zurich, London, Paris, Skopje and Pristina.
